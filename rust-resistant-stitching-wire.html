Rust resistant stitching wire

Rust resistant stitching wire, known in the trade as R.P. wire, has the same steel core as G.I. wire but a much heavier zinc coating. It resists rust for longer, which suits the monsoon season, storage without humidity control and cartons that are stored for months before they ship.

Applications

Where it is used

The wire size is the same as G.I., so a machine set for 23 gauge G.I. runs 23 gauge R.P. without any change. It costs about ten percent more per kilogram, and far less than that per carton.

Used for
Monsoon storage Seasonal stock Long inland transit

Corrugated cartons stored through the monsoon, seasonal stock, warehouses without humidity control, and boxes that are closed long before they are opened.
